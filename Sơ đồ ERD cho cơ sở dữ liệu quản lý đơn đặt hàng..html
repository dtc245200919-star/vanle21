Chi Tiết Các Thực Thể Và Bảng Cơ Sở Dữ Liệu

Danh sách bảng đã qua bước chuẩn hóa dữ liệu (Các khóa chính PK và khóa ngoại FK)

1. DON_VI_KHACH Thực thể chính
Tên cột Loại Mô tả
Ma_DV (PK)VARCHARMã đơn vị khách
Ten_DVNVARCHARTên đơn vị đặt/khách
Dia_chiNVARCHARĐịa chỉ đơn vị
Dien_thoaiVARCHARSố điện thoại liên hệ
2. HANG Thực thể chính
Tên cột Loại Mô tả
Ma_hang (PK)VARCHARMã sản phẩm/hàng hoá
Ten_hangNVARCHARTên hàng hoá
Dv_tinhNVARCHARCái, thùng, kg,...
Mo_ta_hangNTEXTMô tả đặc tính hàng
3. DON_DAT_HANG Thực thể quản lý
Tên cột Loại Mô tả
So_DH (PK)VARCHARSố đơn hàng
Ngay_datDATENgày đặt hàng
Ma_so_ND (FK)VARCHARMã người đặt hàng
4. PHIEU_GIAO_HANG Thực thể giao nhận
Tên cột Loại Mô tả
So_PG (PK)VARCHARSố phiếu giao hàng
Ngay_giaoDATENgày giao hàng thực tế
So_DH (FK)VARCHARThuộc đơn hàng số
Ma_so_NG (FK)VARCHARNgười giao hàng
Ma_so_NN (FK)VARCHARNgười nhận hàng
Ma_so_DDG (FK)VARCHARĐịa điểm giao hàng
5. CHI_TIET_DON_HANG Bảng trung gian (N-M)
Tên cột Loại Mô tả
So_DH (PK, FK)VARCHARSố đơn đặt hàng
Ma_hang (PK, FK)VARCHARMã mặt hàng đặt
So_luongINTSố lượng yêu cầu
6. CHI_TIET_PHIEU_GIAO Bảng trung gian (N-M)
Tên cột Loại Mô tả
So_PG (PK, FK)VARCHARSố phiếu giao
Ma_hang (PK, FK)VARCHARMã mặt hàng giao
So_luongINTSố lượng đã giao
Don_giaDECIMALĐơn giá bán
Thanh_tienDECIMALSố lượng * Đơn giá

Hướng Dẫn Nộp Bài Tập Lên GitHub

Thực hiện 3 bước đơn giản dưới đây để hoàn thành nộp liên kết

1

Tải File Bài Làm

Nhấn nút "Tải ảnh PNG" hoặc "Tải README.md" ở góc trên cùng trang này về máy tính của bạn.

2

Upload Lên GitHub

Tạo Repository mới trên GitHub (hoặc chọn repo sẵn có), chọn Add file ➔ Upload files và tải các file vừa bấm về lên.

3

Coppy & Nộp Link

Sao chép đường dẫn Repository GitHub của bạn (VD: https://github.com/user/quan-ly-don-hang) và dán vào ô nộp bài hệ thống.
